# Superego Software website

Static company website published with GitHub Pages at
`https://www.superegosoft.com/`.

## Domain and search setup

- GitHub Pages custom domain: `www.superegosoft.com`
- `superegosoft.com` should redirect to the `www` address through GitHub Pages.
- GoDaddy domain forwarding must be disabled; the DNS records should point directly
  to GitHub Pages.
- HTTPS should be enforced in the repository's GitHub Pages settings after the DNS
  check succeeds.
- The domain property should be verified in Google Search Console. Submit
  `https://www.superegosoft.com/sitemap.xml` and request indexing for the homepage.
